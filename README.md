# DevJourney for Python — Releases

Download page and auto-update feed for **DevJourney for Python**, an interactive desktop app for learning Python (with FastAPI and Django courses), with a bundled interpreter, IntelliSense, a debugger and an AI tutor.

**[⬇ Download the latest version](https://github.com/artur-kot/devjourney-python-releases/releases/latest)** — Windows installer (`.exe`, NSIS).

### Requirements

- Windows 10 (1903+) with WebView2 (auto-installed)
- Nothing else: Python 3.13 and every package the lessons use ship with the app

---

The application source code is proprietary and lives in a private repository — this repository hosts release artifacts and the updater manifest (`latest.json`) only. Installed apps check here for updates automatically.
